# rlzip

**rlzip** — консольная утилита для сжатия и восстановления текстовых данных с использованием алгоритма RLE (Run-Length Encoding).

Проект реализован на C++23. Помимо алгоритма кодирования и декодирования, содержит собственную реализацию класса `String` и Python-скрипт для автоматизации сборки с поддержкой инкрементальной компиляции.

## Возможности

- Кодирование строк методом RLE.
- Декодирование закодированных строк.
- Чтение входных данных из файлов.
- Запись результата в файл или вывод в консоль.
- Собственная реализация класса `String` для работы со строками.
- Автоматизированная сборка проекта.
- Параллельная компиляция исходных файлов.
- Инкрементальная сборка с использованием SHA-512 для отслеживания изменений исходников и заголовочных файлов.

## Алгоритм работы

В основе утилиты лежит алгоритм RLE (Run-Length Encoding). Он заменяет последовательности одинаковых символов на сам символ и количество его повторений.

Например:

| Исходная строка | Закодированная строка |
|---|---|
| `AAAAABBBCC` | `A5B3C2` |
| `HHHHH` | `H5` |
| `ABC` | `A1B1C1` |

Такой подход позволяет уменьшить размер данных, содержащих длинные последовательности повторяющихся символов.

## Сборка

Клонирование репозитория:

```bash
git clone https://github.com/wnkbll/rlzip.git
cd rlzip
```

Сборка с помощью Python-скрипта:

```bash
python build.py
```

Скрипт автоматически:
1. Находит исходные (`.cpp`) и заголовочные (`.h`, `.hpp`) файлы в директории `src`.
2. Вычисляет SHA-512 хеши файлов.
3. Проверяет наличие изменений относительно предыдущей сборки.
4. Компилирует изменённые исходные файлы в объектные файлы.
5. Выполняет компоновку исполняемого файла при необходимости.

Результат сборки находится в директории `build`:

```text
build/
├── obj/
├── hash.json
└── rlzip
```

## Использование

Общий формат команды:

```bash
rlzip <command> <stream> [-o <path>]
```

### Аргументы

| Аргумент | Описание |
|---|---|
| `command` | Режим работы: `encode` или `decode` |
| `stream` | Входная строка или путь к входному файлу |
| `-o <path>` | Путь к выходному файлу. Если не указан, результат выводится в консоль |

### Кодирование

Кодирование строки:

```bash
rlzip encode "AAAAABBBCC"
```

Результат:

```text
A5B3C2
```

Кодирование с сохранением результата в файл:

```bash
rlzip encode "AAAAABBBCC" -o output.txt
```

Кодирование содержимого файла:

```bash
rlzip encode input.txt -o output.txt
```

### Декодирование

Декодирование строки:

```bash
rlzip decode "A5B3C2"
```

Декодирование с сохранением результата в файл:

```bash
rlzip decode input.txt -o output.txt
```

### Справка

Для получения информации о доступных аргументах:

```bash
rlzip --help
```

Также поддерживается короткий вариант:

```bash
rlzip -h
```

### Основные компоненты

**`main.cpp`**

Точка входа в приложение. Отвечает за обработку аргументов командной строки, чтение входных данных, вызов соответствующего алгоритма и сохранение результата.

**`encoder.cpp / encoder.hpp`**

Реализация алгоритмов кодирования и декодирования RLE. Предоставляет функции:

- `encoder::encode()` — кодирование входной строки.
- `encoder::decode()` — декодирование входной строки.

**`string.cpp / string.hpp`**

Собственная реализация класса `String` для управления строковыми данными.

Класс реализует:
- Динамическое выделение и освобождение памяти.
- Управление длиной и вместимостью строки.
- Копирование объектов.
- Доступ к символам по индексу.
- Добавление символов и последовательностей символов.
- Итераторы и преобразование в стандартные типы `std::string` и `std::filesystem::path`.

**`build.py`**

Скрипт автоматизации сборки проекта на Python. Реализует инкрементальную компиляцию, проверку изменений файлов и параллельную компиляцию исходников.

## Ограничения

- Алгоритм предназначен для работы с латинскими буквами `A-Z` и `a-z`.
- Другие символы не поддерживаются алгоритмом кодирования.
- Входные данные из файлов считываются как отдельное слово, разделённое пробельными символами.
